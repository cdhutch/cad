# Wera Flathead (Slotted) Screwdriver Tray — Design Notes

Gridfinity tray for 3 Wera slotted (flathead) screwdrivers. Built with
ToolTrace.ai's native "Gridfinity" export mode — see
`docs/tooltrace-to-gridfinity-workflow.md` (Part 1) for the general,
reusable procedure this project follows.

Printed as its **own tray in a distinct color** from the companion Phillips
set (`wera-phillips-screwdrivers-tray.md`) — same overall tool collection,
two separate physical trays by design, so they're visually distinguishable
by tip type.
