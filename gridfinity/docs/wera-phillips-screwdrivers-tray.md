# Wera Phillips (Cross-Head) Screwdriver Tray — Design Notes

Gridfinity tray for 4 Wera Phillips screwdrivers. Built with ToolTrace.ai's
native "Gridfinity" export mode — see
`docs/tooltrace-to-gridfinity-workflow.md` (Part 1) for the general,
reusable procedure this project follows.

Printed as its **own tray in a distinct color** from the companion flathead
set (`wera-flathead-screwdrivers-tray.md`) — same overall tool collection,
two separate physical trays by design, so they're visually distinguishable
by tip type.
